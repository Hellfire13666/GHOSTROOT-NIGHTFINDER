## 🌈 The toolkit

| Module | What it does |
| :--- | :--- |
| 🧅 **Source Deck** | Opens manually chosen references to public search and Tor documentation services |
| 🌹 **Quick Add** | Organizes titles, notes, sources, and onion references entered by the user |
| 💜 **Research Vault Fusion** | Imports user-approved CSV and JSON datasets into the local workspace |
| 💙 **Search & Filters** | Narrows entries by keyword and attributed source |
| 🩵 **Export Studio** | Exports filtered CSV, filtered JSON, and a portable full backup |
| 💚 **Vault Memory** | Optionally saves and restores records within the current browser profile |

> **NIGHTFINDER is an organizer, not a crawler.** It does not automatically visit onion addresses, scrape sites, or prove that a listed service exists.

## 🛡️ Privacy first

- **Browser-local records.** The organizer does not send its saved research records to a NIGHTFINDER server.
- **Manual navigation only.** Opening external research links is a deliberate user action; normal browser routing applies, and a standard browser does not become Tor automatically.
- **Unverified by default.** An onion address marked `UNVISITED` is not a verification of availability, legitimacy, legality, or safety.
- **Back up what matters.** Browser profile or privacy cleanup can erase local storage, so export a full backup to retain important data.
- **Clear carefully.** `Clear workspace` clears the active view. To replace the persisted browser copy with an empty workspace, explicitly click `Save locally` afterward.

This repository's published text contains **no private research records, login credentials, personal vault archives, or local QA fixtures**.

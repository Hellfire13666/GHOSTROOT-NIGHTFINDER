# 👻 NIGHTFINDER v1.0.0 // Release notes

**GlitchByte Phantom Labs · Public browser application available**

## What's included

- [Public showcase](https://hellfire13666.github.io/GHOSTROOT-NIGHTFINDER/)
- [Working browser application](https://hellfire13666.github.io/GHOSTROOT-NIGHTFINDER/NIGHTFINDER-HOME.html)
- Approved original artwork: `nightfinder-approved-art.png`
- Manual reference entry, source attribution, search, and filters
- CSV/JSON imports, filtered exports, full backups, and optional browser-local saving

## Testing performed

Firefox testing confirmed the public pages opened and the primary import, save, restore, clear, and export flows worked with non-sensitive sample data. Local CSV/JSON import and export flows were also checked.

Static HTML inspection found no explicit `fetch()`, `XMLHttpRequest`, or `WebSocket` calls in the application. **A complete browser network audit and independent security assessment have not been performed.**

## Privacy and limitations

- Research records remain in the active browser workspace unless explicitly exported or saved to that browser profile.
- Browser storage is not a permanent backup, and hosted and local-file versions use different storage contexts.
- NIGHTFINDER does not automatically visit, verify, or crawl onion services.
- External links open through the user's configured browser and connection.
- Showcase illustrations are not live application controls.

## Download status

The HTML application and approved artwork can be downloaded individually. Keep both files in the same directory for local use.

A separately packaged, version-tagged GitHub Release archive has **not** been published.

For safe handling and private vulnerability reporting, see [SECURITY.md](SECURITY.md).

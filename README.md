# 👻🌈 GHOSTROOT // NIGHTFINDER

**GlitchByte Phantom Labs · Local-first research organizer**

NIGHTFINDER helps people organize **manually collected public onion-service references** in a colorful, browser-based interface. It does not automatically scrape, crawl, verify, or visit onion sites.

## What NIGHTFINDER offers

- 🧅 **Specialist provider deck:** manual reference links for Tor66, OnionLand, Ahmia, and Tor Project documentation
- 🌹 **Quick Add:** save a reference with its title, attributed source, and optional notes
- 💜 **Research Vault Fusion:** import approved CSV and JSON records
- 🌈 **Search and exports:** keyword and source filters, filtered CSV/JSON export
- 💚 **Browser-local Vault Memory:** optional local save and portable backup/restore

## Privacy and safety

**No private research databases, saved browser records, credentials, local computer paths, or recovery archives are included in this repository.** Public directory listings are leads, not evidence that a service is online, safe, or legitimate. Manual external links use the browser's own connection settings, which may not route through Tor.

The **Clear workspace** action affects the current workspace. It does **not** erase the saved browser copy until the user explicitly saves the now-empty workspace.

## Getting started (once release files are available)

Download an approved version, extract the files into one folder, and open `NIGHTFINDER-HOME.html` in a modern browser. Keep its bundled image assets alongside the HTML file. User-imported records remain in the selected browser profile unless exported or cleared.

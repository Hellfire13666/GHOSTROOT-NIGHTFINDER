# 🛡️ NIGHTFINDER // Security & privacy

NIGHTFINDER organizes research references in the browser. It does not scan websites, verify onion services, or provide a Tor connection.

## Report a security concern

If GitHub private vulnerability reporting is available, use it. Otherwise, contact the project owner privately.

**Do not include credentials, personal data, browser profiles, private research, or vault exports in public issues.** Reproduce problems with non-sensitive test records whenever possible.

## Public release checks

Before publishing changes:

- Review the files and final Git diff.
- Check for unexpected network requests and third-party assets.
- Exclude credentials, local paths, private data, test records, backups, and vault exports.
- Confirm permission to publish bundled artwork.

A `.gitignore` file does not guarantee that sensitive files cannot be committed.

## Working safely

- `UNVISITED` means NIGHTFINDER has not verified the address.
- A listed service is not an endorsement of its legitimacy or safety.
- External links use the browser's configured connection; they do not activate Tor.
- Browser-local storage can be erased. Export backups you want to retain.
- After clearing the workspace, choose **Save locally** to persist the empty state.

**Protect the vault. Publish only what you intended.**

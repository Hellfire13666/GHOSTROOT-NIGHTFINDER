# 🛡️ NIGHTFINDER // Security & privacy

NIGHTFINDER is a browser-local organizer for manually entered public research references. It is not a security scanner, crawler, Tor client, or service verification system.

## Reporting

Please **never include passwords, tokens, personal information, private research, browser profiles, or sensitive files** in public issues.

Use GitHub private vulnerability reporting if enabled, or contact the project owner privately. Use synthetic data when reproducing a problem.

## Safe public release checklist

- Confirm the exact application files match the approved and reviewed release.
- Check for unexpected network requests, embedded third-party assets and external scripts.
- Look for credentials, personal paths, local test records, private data and browser profile files.
- Confirm ownership or permission for bundled artwork.
- Exclude QA fixtures, backups, vault exports and recovery archives.
- Review the final Git staging diff. A `.gitignore` is helpful but does **not** make uploads automatically safe.

## Record safety

- `UNVISITED` means an address has not been verified by NIGHTFINDER.
- A listed site is not an endorsement or proof of safety.
- Standard browser links do not automatically use the Tor network.
- Browser-local storage is profile-specific and is not a durable backup.
- Clearing a workspace does not replace the saved browser copy until the user saves the cleared workspace.

**Protect the vault. Publish only what you intended.**

## The toolkit

| Feature | Purpose |
| --- | --- |
| 🧅 Source Deck | Open selected public research resources manually |
| 🌹 Quick Add | Record references, source attribution, titles, and notes |
| 💜 Research Vault Fusion | Import user-approved CSV and JSON records |
| 💙 Search & Filters | Find records by keyword or source |
| 🩵 Export Studio | Export filtered results or a full backup |
| 💚 Vault Memory | Optionally save and restore records in the current browser profile |

**Manual by design.** NIGHTFINDER does not crawl, visit, verify, or automatically retrieve onion services.

## Privacy and storage

- Records stay in the browser workspace unless you choose to export them. Optional browser storage is local to the current profile.
- Use an appropriately configured browser for external services. Clicking a link does not automatically connect through Tor.
- Entries marked `UNVISITED` have not been verified. Directory inclusion is not a safety endorsement.
- Export a full backup for records you need to keep. Browser storage may be cleared.
- To keep an emptied workspace after refresh, use **Clear workspace**, then **Save locally**.

Never commit private research records, credentials, or exported vaults to a public repository.
